# Retail Demand Forecasting - Data Dictionary

## Dataset

Dataset: Store Item Demand Forecasting Dataset

Source: Kaggle - Demand Forecasting Kernels Only

Dataset URL: https://www.kaggle.com/competitions/demand-forecasting-kernels-only/data

File used: train.csv

Total records: 913,000

Total sales: 47,704,512

Date range: 2013-01-01 to 2017-12-31

## Columns

| Column | Data Type | Description |
|---|---|---|
| date | Date | Date of the sales transaction |
| store | Integer | Store identifier |
| item | Integer | Item identifier |
| sales | Integer | Number of units sold |

## Dataset Purpose

The dataset contains historical daily sales records for multiple stores and items.

The historical sales data is used to analyze demand patterns and build a demand forecasting model using PySpark and Spark ML.
